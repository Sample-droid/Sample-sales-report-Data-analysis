#  Sales Performance Dashboard

##  About
Analyzed a retail superstore dataset to uncover
sales trends, top products, and regional performance.

##  Questions Answered
? Which product category sells the most?
? Which months generate the highest revenue
?Which region is most profitable?

## Key Findings
- Technology is the highest selling category
- Sales peak in November and December
- The West region generates the most profit

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Dataset
Kaggle Superstore Dataset
